# 🚤 KHIRAN ONLINE

Welcome to KHIRAN Online, a multiplayer 3D boat simulator set in Khiran, Kuwait!

## 🌊 Online Servers

Choose between three multiplayer lobbies:

- KHIRAN MAIN
- RACE SERVER
- CHILL SERVER

Each lobby supports up to 16 players.

## 🎮 Features

- Explore the ocean and coastline.
- Drive boats and explore with other players.
- Race with friends.
- Chat with other players.
- Floating chat bubbles above players.
- Explore the KHIRAN world.

## 💻 How to Run

1. Install Node.js 20 or newer.
2. Open Terminal in the game folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:10000.

## 🌐 Online Hosting

The game can be hosted using Render.

Build command: `npm install`

Start command: `npm start`

Health check: `/health`

## 👥 Multiplayer

Share your hosted HTTPS game link with friends. Everyone should join the same lobby to play together.

Have fun exploring KHIRAN! 🌴
